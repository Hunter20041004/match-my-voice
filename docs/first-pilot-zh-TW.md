# 第一輪多人測試

這輪要檢查同一套 Skill 能不能分別學到不同人的表達方式。這是小規模產品測試，不是統計研究。

## 測試者與材料

- 找 3～5 位以繁體中文溝通、表達方式有差異的測試者，以 P01、P02 等匿名代號記錄。
- 每人提供 3～5 段自己認為自然、確定由本人撰寫或說出的文字；另留一段不讓 Skill 事先看到。
- 標記材料的場合、對象、是說話或寫作，以及是否曾被他人或 AI 大幅修改。
- 不把姓名、帳號、原始文件網址、原始樣本或口吻檔放進公開結果。

## 分開保存

- 共用 Skill 只放分析、校準與改寫方法。
- 每位測試者擁有獨立的 `VOICE.md`，只根據本人的樣本與回饋更新。
- 多位測試者遇到相同的分析問題時，才考慮修改共用 Skill。

## 測試方法

1. 用該人的樣本建立口吻檔，試寫一小段，讓本人指出最不像自己的地方並校準。
2. 準備兩個新的寫作任務。一般版只能看任務內容；個人口吻版額外讀取該人的口吻檔。兩邊使用相同模型和內容限制，且在隔離的對話中產生。
3. 隨機把兩版命名為 A、B。本人不知道版本來源，選出較像自己、較願意使用的版本，並直接修改最不像自己的一句。
4. 用同一份不含私人資訊的任務，產生自己的口吻版和隨機另一人的口吻版，檢查本人能否辨認自己的版本。
5. 分開記錄事實錯誤。任何捏造經歷、數字或承諾都屬重大問題。

## 第一輪判斷

- 個人口吻版在非平手盲選中，比一般版更常被選為「比較像本人」。
- 多數測試者至少有一個任務更願意直接使用個人口吻版，不能只有 Skill 作者通過。
- 多數測試者能在自己的口吻版和他人口吻版之間選出自己的版本。
- 個人口吻版不能產生更多事實錯誤。
- 個人偏好沒有進入共用 Skill，也沒有出現在另一人的口吻檔。

若沒有通過，先確認問題來自樣本、分析、寫作遵循、對話隔離或測試題目，只修改有證據出錯的部分。

## 隱私

測試前說明使用的 AI 服務、資料保存位置與保留範圍。不因同意測試就推定同意公開。公開 Issue 只放匿名問題描述；私人原文與完整口吻檔由本人保管，副本依事前約定刪除。
